# Qelly premium Figma master specification

## Execution

Run the repository plugin in `figma-plugin/`. It generates editable pages, semantic color variables with dark/light modes, text and paint styles, reusable components, and 24 high-fidelity desktop/mobile master frames. No hosted Figma URL is claimed because the connected environment cannot publish into the user's Figma account.

## Component requirements

- Auto Layout, responsive constraints, semantic naming, variables, styles, components, and instances.
- Neutral surface hierarchy, restrained burgundy identity, semantic data colors.
- Compact application shell, ranking table, realistic OHLC chart, market pulse, source/freshness/confidence, explanation, and provenance patterns.
- Every frame records viewport, mode, state, data boundary, accessibility behavior, and responsive intent.

## Review boundary

The generator is executable and editable, but generated frames must be opened and visually reviewed in Figma before any fidelity or quality claim. Frame count is not a quality measure.
