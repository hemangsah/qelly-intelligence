# Official reference screenshot evidence

The PR-only `Qelly UI Rescue Review` workflow attempts browser screenshots of the current official CoinGlass, CoinMarketCap, and WorldQuant home pages for private design review.

Network access, consent overlays, bot protection, geolocation, and client-side rendering may prevent an official-page capture. A failed capture is recorded in `research/official-screenshot-status.json`; it is not fabricated and does not fail the Qelly implementation artifact.

Official screenshots are evidence only. They are not bundled into the compiled Qelly preview, used as product assets, or treated as a license to copy trade dress.
