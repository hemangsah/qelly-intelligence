# Editable Figma handoff - Part 22

A hosted native Figma URL could not be created because no authenticated Figma connector is available in this workspace. The included development plugin creates the editable Qelly document directly inside Figma Desktop.

## Install and generate

1. Extract the Part 22 package.
2. Open Figma Desktop and create a blank Design file.
3. Choose `Plugins > Development > Import plugin from manifest...`.
4. Select `figma-plugin/manifest.json`.
5. Run **Qelly Sovereign Design Generator**.
6. Generate the primary persona for 47 editable frames, or all personas for **282 editable frames**.

## Generated content

- Permanent gradient and protected brand rules
- Six market-persona foundations
- Typography hierarchy and light/dark polarity rules
- Spacing, grid, radius and elevation systems
- Navigation, command bars and page heroes
- Buttons with default, hover, pressed, focus and disabled states
- Cards, bento panels, tables, forms and evidence modules
- Candlestick, volume, indicator and market-status structures
- Motion annotations and reduced-motion equivalents
- 47 route structures for each selected persona

All generated elements are editable Figma layers and frames. Font files are not bundled.
