# Qelly Theme Intelligence System

## Permanent typography lock

IBM Plex Sans Variable is Qelly’s permanent canonical font across the public website, application UI, data tables, charts, command palette, dialogs, drawers, tooltips, mobile navigation and every future route. Theme, appearance, persona, mindset, intensity, visual-pack and user-override layers cannot replace it. GT Eesti remains inactive unless Qelly obtains the correct commercial web licence and the founder explicitly approves activation.

## Layered architecture

1. Appearance resolves dark, light, OLED, high contrast, system or scheduled mode.
2. Theme family selects one of 13 curated palettes.
3. Persona selects one of six governed operating profiles.
4. Mindset selects one of four persona-specific working contexts, for 24 total.
5. Aggressive Alpha intensity selects Focused Edge, Tactical Surge, Conviction Strike or Redline Apex.
6. Aggressive Alpha visual pack selects Crimson Vector, Obsidian Strike, White Heat, Ember Protocol, Apex Monochrome or Scarlet Circuit.
7. User overrides tune validated accent, density, emphasis, market palette, borders, selected state, focus and motion without replacing protected semantics.

## Protected semantics

Positive, negative, warning, informational, evidence, focus, selected, stale, delayed, simulated and unavailable roles are central tokens. Custom accents and imported presets cannot replace positive or negative market meaning, inject CSS, load external resources or alter the canonical font.

## Persistence

Anonymous users receive versioned local persistence. Authenticated preferences are stored through the existing tenant/workspace/user-scoped revision-aware PreferenceStore. Legacy version-1 profiles are migrated to version 2. Corrupt local preference data recovers to the governed default.

## Validation

The implementation validates 119 required semantic tokens, 13 theme families across dark/light/OLED/high contrast, every Aggressive Alpha level and visual pack, portal inheritance, chart/table semantics, custom accent safety, preset import security, reduced motion, font flash prevention, theme flash prevention and responsive behavior.
