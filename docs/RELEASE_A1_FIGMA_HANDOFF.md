# Release A1 Editable Figma Handoff

No authenticated Figma connector is available in this workspace, so a hosted Figma URL or native `.fig` file was not created.

`QELLY_RELEASE_A1_FIGMA_EDITABLE_HANDOFF.zip` contains a Figma development plugin that creates editable foundations and the three changed product screens: Secure Login, Create Organization, and Account Session. It also creates an architecture/developer-handoff frame.

## Install
1. Extract the ZIP.
2. Open a blank Figma Design file.
3. Use **Plugins -> Development -> Import plugin from manifest**.
4. Select `figma-release-a1/manifest.json`.
5. Run **Qelly Release A1 Production Foundation**.

The permanent Qelly gradient and typography hierarchy are preserved. No font files are bundled.
