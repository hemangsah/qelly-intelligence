# Qelly Brand Usage Guide

Use the horizontal lockup for opening, hero, authentication and wide shell contexts. Use the symbol for collapsed navigation, mobile compact headers, loading support and icon surfaces.

Brand node colors are identity details, not market state labels. Market positive and negative semantics remain governed by the existing semantic tokens and must not be inferred from logo nodes.

Light mode uses neutral porcelain surfaces without pink atmosphere. Dark mode uses neutral near-black surfaces with controlled burgundy identity.
