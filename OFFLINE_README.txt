QELLY INTELLIGENCE PART 22 - OFFLINE / OPTIONAL LIVE MARKET WEBSITE

1. Install Node.js 22 or newer.
2. Extract this entire folder.
3. Windows: double-click START_QELLY_WINDOWS.bat.
4. macOS/Linux: run ./START_QELLY_MAC_LINUX.sh.
5. Open http://127.0.0.1:4480.

The website and deterministic fallback work offline. Public Binance/CoinDCX candle requests require internet access and QELLY_LIVE_MARKET_ENABLED=true. All market connectivity is read-only.
