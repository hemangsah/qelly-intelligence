# Qelly Public Beta Release Dependency Graph

Foundation commit: `94fbd4ff91c0d61f87e42724038f03fa5c36f97a`
Program branch: `release/qelly-public-beta-v1`

## Dependency order

1. Approved brand and Theme Intelligence foundation
2. Durable project-state and capability inventories
3. Truth-state and evidence metadata contracts
4. Environment and feature-flag model
5. Runtime configuration and safety invariants
6. Provider adapter and observability interfaces
7. Read-only provider implementations with legal/terms review
8. Public-beta route activation and truthful state presentation
9. Staging, canary, rollback and operational readiness
10. Public release only after Prompt 3 audit and release gates

## Release A — must launch

- approved responsive visual foundation;
- static/public routes that pass accessibility and browser checks;
- truthful live/delayed/simulated/unavailable labels;
- source, freshness and lineage presentation;
- runtime safety validation;
- error and provider health reporting;
- documented known limitations;
- rollback procedure and release evidence.

## Should launch

- selected free/public read-only providers after current terms verification;
- deterministic local calculators selected by Prompt 2;
- provider-health and beta-readiness dashboards;
- cache and stale-state handling.

## Post-launch

- broader provider coverage;
- strategy development and marketplace capabilities;
- advanced order-flow, options and on-chain modules;
- expanded account aggregation.

## Blocked or licensed

Any provider requiring redistribution rights, paid market data, jurisdiction approval, production credentials or signed commercial terms remains blocked until evidence is recorded.

## Deliberately disabled

- real-money execution;
- custody;
- deposits and withdrawals;
- private-key or seed-phrase storage;
- autonomous strategy execution.
