# Qelly synthesis decisions

## Direction

Qelly Phase 0 is **quiet institutional luxury + quant terminal density + editorial research intelligence + evidence-backed provenance**.

## Decisions

1. **Neutral canvas dominates.** Near-black, charcoal, and restrained dividers form the analytical workspace. Burgundy is reserved for the Q mark, selected identity states, one primary action, and rare evidence emphasis.
2. **Gradients are rare.** The Phase 0 application uses gradients only for two compact brand marks. Panels, KPI modules, navigation, table rows, badges, and the application canvas are flat neutral surfaces.
3. **The ranking table is primary.** It precedes the chart in document and visual order, supports 23 governed columns, and remains directly accessible in the initial desktop experience.
4. **The chart behaves like market software.** Deterministic data uses open, high, low, close, volume, open interest, and funding with regime changes and shocks. Candlestick, line, area, crosshair, tooltip, axes, timeframe, and keyboard inspection are available.
5. **Three layouts solve different jobs.** Discovery prioritizes scanability; Terminal adds derivatives pressure and provider agreement; Research adds a citation-shaped evidence brief. Personas affect hierarchy and defaults rather than acting as color skins.
6. **Typography is restrained.** Medium weights dominate; heavy weights are reserved. Numbers use a mono/tabular stack. No essential information is intentionally set below 12px in accessible modes.
7. **Icons are a consistent SVG system.** Temporary Unicode glyphs are removed from the redesigned shell and Asset Rankings route. Every actionable icon has an accessible name.
8. **Truth state is compact.** One status center states static preview, deterministic data, backend unavailability, and non-execution. Source, freshness, and confidence remain attached to data without repeating a large DEMO badge.
9. **Mobile is a separate composition.** It uses a compact header, bottom navigation, prioritized rows, expandable details, horizontal metric strips, and bottom sheets. The desktop table is not squeezed into the viewport.
10. **Motion preserves calm.** Fast transitions support controls; deliberate motion is limited to navigation, drawers, sheets, and mode continuity. Reduced motion removes travel and looping ticker animation without removing meaning.

## Reference translation

- From CoinGlass: derivatives density and task-adjacent controls.
- From CoinMarketCap: discovery breadth, rankings primacy, and scanable columns.
- From WorldQuant: editorial restraint, confident typography, and deliberate pacing.
- From Qelly: source quality, freshness, confidence, provider disagreement, Explain This Move, and Decision Provenance.

No reference product is cloned. Exact layout, CSS, icons, chart skin, copy, data, APIs, and trade dress are excluded.
