# Qelly premium design review checklist

## Visual direction

- [ ] Neutral institutional surfaces dominate.
- [ ] Burgundy is an accent, not a canvas fog.
- [ ] Gradients are rare and purposeful.
- [ ] Typography uses restrained medium hierarchy and tabular numerals.
- [ ] Icons are finished SVGs with consistent stroke and optical size.
- [ ] Composition is not a repeated card wall.

## Market product

- [ ] Rankings table is a primary surface.
- [ ] Chart uses realistic OHLC, volume, axes, crosshair, tooltip, and source information.
- [ ] Discovery, Terminal, and Research layouts solve different tasks.
- [ ] Derivatives pressure, source, freshness, confidence, and evidence are visible without noise.
- [ ] Explain This Move is reachable from row, chart, and intelligence modules.

## Mobile

- [ ] No desktop rail or squeezed table.
- [ ] Compact header, context title, bottom navigation, safe areas, prioritized rows, expandable details, and bottom sheets.
- [ ] No clipping or horizontal page overflow at 360, 390, and 430 widths.

## Accessibility and motion

- [ ] WCAG 2.2 AA contrast and non-color states.
- [ ] Keyboard navigation and visible focus.
- [ ] Table semantics and chart text summary.
- [ ] Reduced motion removes travel and loops but preserves meaning.
- [ ] Touch targets and zoom/reflow behavior are annotated.

## Truth and originality

- [ ] Static review state is stated once clearly.
- [ ] No unsupported live, provider, persistence, or execution claim.
- [ ] No reference logo, copy, exact layout, proprietary data, chart skin, CSS, or animation is reproduced.
- [ ] Every generated master frame is opened and reviewed before a quality claim.
