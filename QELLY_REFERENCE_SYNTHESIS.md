# Qelly reference synthesis and originality record

The three supplied reference screenshots and the requested WorldQuant principles were treated as capability references, not templates.

## Useful principles retained

### High-density market products

- compact global context;
- discoverable market categories;
- sortable asset tables;
- sticky identity and context;
- chart-first asset investigation;
- fast access to watch, compare, alert, and related evidence;
- explicit responsive changes rather than a scaled desktop.

### Editorial research products

- confident typography;
- purposeful negative space;
- narrative progression;
- restrained motion connecting propositions;
- research and methodology treated as first-class product surfaces.

### Qelly-specific synthesis

Qelly adds a persistent truth layer that the references do not define as its central interaction model:

- source, observation, ingestion, freshness, quality, and confidence travel with the value;
- data disagreement and fallback remain visible;
- Explain This Move is bound to an evidence package rather than an uncited chat answer;
- considered decisions remain distinct from execution;
- provenance has a graph view and an accessible list alternative;
- operating personas change hierarchy and behavior, not only color.

## Explicit non-copying decisions

- No reference logo, wordmark, slogan, illustration, icon set, table styling, or page composition was copied.
- Qelly uses its own darkest-burgundy-to-merlot signature, porcelain analytical surfaces, semantic evidence colors, and provenance node language.
- CoinMarketCap and CoinGlass are not data sources for this implementation. No scraping or private API use was introduced.
- The static dataset is an internal deterministic Qelly demo and is labelled not live.
- No reference product is named inside the end-user interface.
