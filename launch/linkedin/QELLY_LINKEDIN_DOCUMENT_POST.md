# Qelly Global Public Beta
## Building financial software that says what is true

### Page 1 — The problem

Many financial tools show a result without making the formula, assumptions, data source, freshness or limitations easy to inspect.

Qelly was built around a different principle:

**A number is more useful when its evidence is visible.**

---

### Page 2 — What Qelly includes

- 151 deterministic financial formulas
- 54 technical indicators
- 70 public product routes
- local-first saved calculations
- revision history and restore
- methodology and input/output contracts
- four governed themes and responsive states
- offline-safe deterministic tools

---

### Page 3 — Product truth

Qelly distinguishes:

- deterministic local
- user entered
- live provider
- delayed provider
- cached provider
- stale provider
- simulated demonstration
- unavailable

A configured adapter is not called live. A fixture is not called live. A cached value is not called live.

---

### Page 4 — Local first, cloud optional

Deterministic tools work without an account.

Cloud synchronization is explicit opt-in.

Local records are not uploaded silently.

Conflicts are detected rather than overwritten.

Offline queues preserve user intent until a verified connection returns.

---

### Page 5 — Security boundaries

Qelly's public-beta architecture includes:

- Postgres row-level security
- tenant ownership policies
- CSRF and CORS validation
- content-security policy
- malicious JSON and import rejection
- CSV injection protection
- server-side Turnstile verification
- rate limits and idempotency
- secret separation and log redaction

---

### Page 6 — What Qelly does not do

Qelly does not:

- trade
- custody assets
- accept deposits
- process withdrawals or transfers
- sign wallet transactions
- request private keys or seed phrases
- execute through brokers or exchanges
- make autonomous investment decisions
- provide personalized financial advice

---

### Page 7 — Evidence before launch

The accepted deterministic foundation includes:

- 151/151 formulas

- 1,944/1,944 browser acceptance records

### Page 8 — Free public beta

Qelly uses legitimate free tiers and a free platform subdomain.

No domain purchase.
No paid plan.
No payment method.
No billable overages.

When capacity becomes constrained, Qelly preserves deterministic local features, prefers bounded cache and suspends nonessential writes before a surprise cost.
