## Technical build story

Qelly's public beta was not released from a dashboard screenshot or a happy-path demo.

The deterministic foundation was frozen and tested first:

• 151/151 formulas
• 54/54 indicators
• 1,944/1,944 browser acceptance records
• 54/54 automated accessibility checks
• 19/19 saved-calculation lifecycle actions
• 429/429 governed UI states

Prompt 2C then added a vendor-neutral production layer: Postgres migrations, row-level security, tenant policies, opt-in local-first sync, conflict handling, provider provenance, bounded caching, CSRF/CORS/CSP controls, malicious import protection, rate limits, Turnstile verification contracts, privacy minimization, rollback procedures and zero-cost quota governance.

The important design decision: configured is not the same as live.

A provider adapter is never labelled live until a real request is proven. Cloud sync is never labelled active until a real database, authentication journey and cross-user isolation test pass. When those services are unavailable, Qelly keeps deterministic local tools working and says exactly what is unavailable.

## Security and product-truth post

A production-looking interface can still be misleading.

For Qelly, I adopted a stricter rule: **a capability is not live because code for it exists.**

Authentication is live only after real sign-up, verification, sign-in, expiry and recovery pass.

Cloud sync is live only after real upload, download, offline recovery, conflict handling and cross-user isolation pass.

Provider data is live only after a permitted real request proves its source and observation time.

Until then, the UI says authorization required or unavailable—and deterministic local tools continue working.

The public beta also prohibits trading, custody, transfers, wallet signing, private-key handling and autonomous investment decisions.

That may sound conservative. For financial software, truth is a feature.

## FAQ responses

**Is this a trading platform?**
No. Qelly is read-only. It does not place trades, hold assets, process deposits/withdrawals or sign wallet transactions.

**Does it give investment advice?**
No. It provides educational calculations, indicators and research-support information with assumptions and limitations. It does not provide personalized financial advice or guaranteed returns.

**Do I need an account?**
No account is required for deterministic calculators, formula/indicator browsing or local saved calculations. Cloud account features remain unavailable until their real service is authorized and verified.

**Is the data live?**
Each connected datum must show its provider and state: live, delayed, cached, stale, simulated or unavailable. The public beta never calls a fixture or configured adapter live.

**Why are some cloud features unavailable?**
Qelly enables them only after a real project passes migrations, authentication, recovery, cross-user isolation and synchronization tests.

**Can I connect a wallet or exchange?**
No. Qelly does not request wallet seeds, private keys, exchange credentials or brokerage execution access.

**How should I report a problem?**
Use the Support page and official GitHub issue templates. Never submit credentials, tokens, seed phrases or sensitive financial records.
