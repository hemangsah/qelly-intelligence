Support and feedback

Protected feedback submission is not active until Turnstile and the cloud endpoint are authorized. The official GitHub issue flow is the current public fallback.

What to report

  • Incorrect deterministic output with the formula ID, inputs and expected reasoning.
  • Broken navigation, mobile overflow or offline behavior.
  • Keyboard, focus, label, contrast, screen-reader or reduced-motion issues.
  • False or unclear provider freshness, confidence, attribution or fallback labels.
  • Privacy, cross-user isolation or secret-exposure concerns.

Do not submit

Never submit passwords, API tokens, session cookies, identity documents, wallet private keys, seed phrases, brokerage credentials or sensitive financial records. Redact personal information from screenshots and logs.

Open an issue

Use the repository's issue templates and choose the closest category. Include the route, browser, device, public release SHA, exact steps, expected behavior and actual behavior. Security-sensitive reports should follow the repository security policy rather than a public issue.

Open the official Qelly issue form

Account export or deletion

Cloud account export and deletion become available only after production authentication is activated and verified. Until then, Qelly operates in deterministic local mode; local browser records can be removed through the application's saved-calculation controls or browser storage settings.
