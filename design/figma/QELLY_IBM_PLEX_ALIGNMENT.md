# Qelly Figma typography alignment

The editable Figma generator must use **IBM Plex Sans** for all display, body, table, control, chart-label and numeric-evidence roles so the design handoff matches the production website.

- Production web font: IBM Plex Sans Variable, self-hosted under SIL Open Font License 1.1.
- Figma target: IBM Plex Sans Regular and Medium/SemiBold where available.
- Figma fallback: Inter only when IBM Plex Sans is unavailable in the local Figma environment; the fallback must be resolved before design approval.
- GT Eesti Pro Display and Text remain an inactive commercial reference until Qelly owns an appropriate web licence and supplies licensed font files.
- Geist and Geist Mono are superseded historical directions and must not be used in newly generated master frames.
- Qelly keeps semantic inline SVG icons and does not adopt the reference site's private icon font.
