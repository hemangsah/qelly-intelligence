# Archived workflow definitions

These YAML files are retained as historical source, outside `.github/workflows/`, so GitHub Actions does not schedule them. They were retired after reference and history checks showed no open pull request depends on the Prompt 2A, Prompt 2B, corrective-branch or forced-legacy visual gates. Their captured evidence remains in `project-state/`; active gates use permanent purpose names in `.github/workflows/`.

Do not reactivate an archived workflow by copying it back. If a capability is needed again, create a current purpose-based workflow with an explicit owner, trigger and release contract.
