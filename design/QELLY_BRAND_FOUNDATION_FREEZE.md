## Frozen foundation

The following are approved and governed as the Qelly public-beta visual baseline:

- the current Qelly logo geometry and approved source assets;
- IBM Plex Sans Variable as the canonical product typeface;
- burgundy brand identity and semantic green/red decision nodes;
- Theme Intelligence architecture and all 13 approved theme families;
- dark, porcelain light, OLED and high-contrast behavior;
- application shell, navigation, command palette and portals;
- charts, tables, evidence components and semantic market colors;
- opening experience, authentication branding and product states;
- responsive behavior, mobile navigation clearance and reduced motion.

## Change boundary

No broad redesign or competing visual system is permitted before the connected public beta. Feature teams must consume approved tokens, primitives and components rather than fork new systems.

Permitted changes without a new visual program are limited to:

1. accessibility corrections;
2. correctness and security defects;
3. responsive-layout defects;
4. evidence-backed usability improvements;
5. provider-state, data-quality and product-truth presentation required by the public-beta program.

Any modification to logo geometry, canonical typography, semantic market meaning, theme architecture or broad shell identity requires a separately reviewed and approved visual program.

## Automated governance expectations

Repository validation must fail when:

- IBM Plex is replaced or an unauthorized product font is loaded;
- approved logo geometry changes outside governed source and generation paths;
- theme tokens are bypassed by arbitrary presentation values;
- new arbitrary brand colors are introduced without token governance;
- dark/light semantics materially regress;
- user-downloadable artifacts contain prohibited font binaries;
- semantic positive, negative, warning, evidence, stale or unavailable meanings are reassigned.

## Immutable checkpoints

- `qelly-design-foundation-v1` remains immutable at the approved Theme Intelligence foundation.
- `qelly-brand-foundation-v1` must identify the exact verified PR #13 merge foundation.

## Public-beta rule

This freeze does not claim that every Qelly feature is live or connected. Product capability and data state must remain truthfully classified as live, delayed, cached, deterministic local, simulated, estimated, embedded, unavailable, stale, partial, authorization-required, licence-required or demo.
