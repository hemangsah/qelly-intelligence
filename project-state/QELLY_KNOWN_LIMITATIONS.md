# Qelly Known Limitations

## Public deployment

The GitHub Pages URL is verified for exact commit `94fbd4ff91c0d61f87e42724038f03fa5c36f97a`, but it is a public static/read-only visual preview. It does not prove authenticated backend services, persistence, connected external providers, custody or trading.

## Static and deterministic data

- Static-preview values are deterministic demo records, not live provider observations.
- A visual route, source reference or feature registry row does not prove backend implementation or connectivity.
- The API inventory contains source references requiring executable verification before Connected classification.

## Public-beta foundation

- Provider adapter interfaces exist, but no market, broker, exchange, wallet, bank or observability provider is connected by Prompt 1.
- Observability events are defined and secret-redacted, but no production reporting sink is connected.
- Environment-specific production configuration and credentials remain external.

## Deliberately excluded

- real-money trading;
- custody;
- deposits and withdrawals;
- private-key or seed-phrase storage;
- autonomous execution.

Prompt 2 is required for focused product implementation. Prompt 3 is required for the exhaustive frontend/backend/database/security/provider audit and any connected public-beta release claim.
